# User Guide

This guide explains how to use every feature of Task Tracker. No account, no setup — just open the page and start typing.

## 1. Adding a task

1. Click the input field at the top labeled *"What needs to be done?"* (or press **Tab** until it is focused).
2. Type your task. The input accepts up to 200 characters.
3. Press **Enter** (or click the **Add** button).

The new task appears at the bottom of the list. Empty submissions are ignored, so you cannot accidentally create a blank task.

## 2. Completing a task

Click the **checkbox** on the left of any task to mark it as completed. Completed tasks:

- Show a **strike-through** on the title.
- Drop into the **Completed** filter view.
- Are counted separately in the "items left" counter at the top.

Click the checkbox again to un-complete the task.

## 3. Filtering tasks

Use the three filter buttons near the top of the task list. Each filter shows a live count of the tasks it contains:

| Filter | Shows |
| --- | --- |
| **All** | Every task, completed and active. (Default.) |
| **Active** | Only tasks that are not yet completed. |
| **Completed** | Only tasks that are completed. |

The active filter is highlighted. The filter resets to **All** when you reload the page.

## 4. Reading your stats

Above the task list, three stat cards show:

- **Total** — every task you have.
- **Active** — tasks that are still pending.
- **Completed** — tasks you have finished.

These counts update live as you add, complete, or delete tasks.

## 5. Deleting a task

Click the **×** button on the right of a task to remove it. Deletion is immediate and permanent; there is no undo. To remove many completed tasks at once, use **Clear completed** (see below).

## 6. Clearing all completed tasks

When at least one task is completed, a **Clear completed** link appears in the bottom-right of the task list. Click it to permanently delete all completed tasks in one action. Active tasks are not affected.

## 7. Light and dark theme

Click the **sun/moon button** in the top-right of the header to toggle between light and dark mode. The app remembers your choice across sessions. On first visit, the app uses the theme your operating system reports (`prefers-color-scheme`).

## 8. Keyboard shortcuts

| Key | Action |
| --- | --- |
| **Tab** | Move focus through controls |
| **Enter** (in the input) | Submit and add a task |
| **Enter** (on a focused checkbox) | Toggle the task |
| **Space** (on a focused button) | Activate the button |
| **Esc** (on a focused task) | Blur the element |

## 9. Where your data lives

Everything you create is stored **only in your browser's local storage**. It never leaves your device. If you:

- Open the app in a different browser, you will see an empty list.
- Use a private/incognito window, tasks created there will not appear in your normal window.
- Clear your browser's site data, your tasks will be erased.

To back up your data, use your browser's regular bookmark/export workflow for site data.

## 10. Troubleshooting

| Symptom | Likely cause | Fix |
| --- | --- | --- |
| Tasks disappear after closing the tab | Browser is set to clear site data on exit | Change browser settings or use a normal window |
| Theme resets every visit | Private/incognito mode or localStorage disabled | Use a normal window |
| Add button does nothing | Empty input | Type at least one non-whitespace character |
