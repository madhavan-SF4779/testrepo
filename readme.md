# Daily Work Tracker

A production-ready React and TypeScript productivity workspace with task management, daily check-ins, analytics, activity history, themes, and local persistence.

## Features

- Persistent demo authentication with login and logout
- Dashboard metrics for total, completed, active, and overdue tasks
- Dynamic completion progress and productivity indicators
- Full task create, edit, delete, search, filter, and completion flows
- Low, Medium, High, and Critical task priorities
- Daily work logs with focused hours, mood, and reflections
- Weekly and monthly interactive Recharts visualizations
- Recent completion activity timeline
- Responsive desktop, tablet, and mobile navigation
- Light and dark themes
- Browser local storage persistence

## Project structure

- `src/components` — reusable application shell, forms, modals, and cards
- `src/views` — dashboard, task management, and analytics screens
- `src/data` — realistic starter tasks, work logs, and chart data
- `src/hooks` — local persistence hook
- `src/test` — shared test setup
