# Daily Work Tracker

A complete modern frontend application for daily work tracking, task management, productivity analytics, activity timelines, and local user persistence.

## Features

- Login and logout flow with persisted session state
- Dashboard metrics for total, completed, pending, overdue, and productivity score
- Daily work status logging with focus, hours, mood, and summary
- Todo create, edit, delete, search, and filter workflows
- Low, Medium, High, and Critical priority levels
- Dynamic completion progress bar
- Weekly and monthly productivity charts
- Priority distribution visualization
- Completed work activity timeline
- Light and dark themes
- Responsive layouts for desktop, tablet, and mobile
- Local persistence using browser storage
