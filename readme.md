# form & field — React storefront

This repository started as a minimal test repository with only a short welcome README. It now contains a small React e-commerce storefront built with Vite.

## What's included

- A responsive storefront landing page with a promotional banner, navigation, hero section, and featured collection.
- Four sample products with category filters (All, Home, Kitchen, and Accessories).
- Interactive add-to-bag buttons and a live bag item count.
- Product photography and a responsive layout for mobile and desktop.

## Project structure

- `index.html` — Vite's HTML entry point.
- `src/main.jsx` — React application bootstrap.
- `src/storefront.jsx` — storefront UI and product interactions.
- `src/styles.css` — responsive visual styling.
- `package.json` — React dependencies and Vite development/build scripts.

Product data currently lives in `src/storefront.jsx`; this is a front-end demo and does not connect to a payment, inventory, or backend service. Product images and fonts are loaded from Unsplash and Google Fonts.
